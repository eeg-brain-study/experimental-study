This repository provides the **replication package**, **analysis scripts**, and **supplementary materials** for the paper.

## Analysis Pipeline (Python)

The `/Analysis` directory contains standalone Python scripts derived from `PipelineCSV.ipynb`. Run them in order from the project root:

| Script | Description |
|---|---|
| `01_merge_csv.py` | Merges per-wave CSV files from `data/REG` into a single `EEG_ALL_WAVES_REG.csv` |
| `02_normality_test.py` | Shapiro-Wilk normality test for the Frontal channel across each band and activity (BL01–BL04) |
| `03_descriptive_stats.py` | Descriptive statistics: mean per band, per band × activity, overall mean, and Frontal pivot table |
| `04_friedman_test.py` | Friedman test + Nemenyi post-hoc on Frontal power across activities within each frequency band; reports Kendall's W as effect size |
| `05_heatmap.py` | Generates `eeg_heatmap.png` — a diverging heatmap of average Frontal EEG power across testing activities and frequency bands |

### Requirements

```bash
pip install -r requirements.txt
```

### Execution order

```bash
python Analysis/01_merge_csv.py       # must run first — generates EEG_ALL_WAVES_REG.csv
python Analysis/02_normality_test.py
python Analysis/03_descriptive_stats.py
python Analysis/04_friedman_test.py
python Analysis/05_heatmap.py
```

## EEG Processing Pipeline (MATLAB)

The MATLAB scripts used to process the raw EEG recordings are organized as follows:

| Directory    | Purpose                                      |
|--------------|----------------------------------------------|
| `/ICA`       | EEG import, filtering, ICA decomposition     |
| `/UniGui`    | GUI-based epoch extraction and preprocessing |
| `/EEGQ`      | Spectral power computation and CSV export    |
| `/MergeData` | Merging multiple EDF or SET recordings       |

### Requirements

* **MATLAB R2018b** or later
* **EEGLAB v2023.1** or later [EEGLAB instalation guide](https://eeglab.org/tutorials/01_Install/Install.html) 

### Execution Order

1. Run **`ICA/ICA_Script.m`** using all `.EDF` files from the experiment.
2. Execute **`UniGui/Unified_GUI.m`** with all `.SET` files generated by `ICA_Script.m`.
3. Run either:

   * **`EEGQ/eeg_q_Script.m`**
   * **`EEGQ/eeg_q_Unified_Region_Script.m`**

     using the `.SET` files produced by `Unified_GUI.m`.

> If you need to merge `.EDF` files before step 1, use **`MergeData/scriptMergeEDF.m`**.
> If you need to merge `.SET` files, use **`MergeData/MergeSET.m`**.
